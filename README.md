# Inventario de Educología / UNA

Prototipo en HTML, CSS y JavaScript para probar inventario, cuentas docentes, solicitudes, aprobación y devolución de equipos.

Abre `index.html` con Live Server en VS Code o visita la publicación de GitHub Pages cuando esté habilitada.

## Cuentas de demostración

| Perfil | Correo | Contraseña |
| --- | --- | --- |
| Administración | admin@educologia.test | admin123 |
| Docente | docente@educologia.test | docente123 |

Usa datos ficticios y contraseñas de prueba. Las cuentas están en el código y los registros se guardan en el navegador. Las pestañas de un mismo navegador se actualizan automáticamente. Para compartir solicitudes entre equipos se necesita un servidor con base de datos y autenticación.

## Archivos

- `index.html` contiene las pantallas y formularios.
- `css/estilos.css` contiene el diseño.
- `js/app.js` contiene las acciones y el almacenamiento local.
