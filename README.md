# Inventario de Educología · UNA

Abre esta carpeta en VS Code. Para ver la página, abre `index.html` en el navegador. Guarda los cambios y actualiza la página para verlos.

- `index.html` contiene la estructura de la página.
- `css/estilos.css` contiene el diseño.
- `imagenes/` queda disponible para el logo y otros recursos visuales.

La primera pantalla contiene el encabezado. El siguiente paso es escribir juntos la tabla de inventario en HTML.
